## 🛠️ Troubleshooting

### The app won't start
- Make sure you have the latest Windows updates
- Right-click the file and select "Run as administrator"
- Check if your antivirus is blocking it – add an exception

### The app can't find my game
- Ensure Civilization VI is installed and has been run at least once
- Click "Browse" in the app and manually locate your save folder
- Default save location: `Documents\My Games\Sid Meier's Civilization VI\Saves`

### Performance is slow
- Close other programs while using the toolkit
- Lower the graphics settings in the Performance Booster tab
- Restart the app after long gaming sessions
